## key_binding
confirm -> z
cancel -> x
menu -> c
back -> backspace
up -> up
down -> down
left -> left
right -> right
submit -> enter

## game_rules
- [FACT] Dialogue boxes advance with Z, one page per press; wait until the text finishes scrolling before pressing again.
- [FACT] The name-entry screen is a letter grid plus one bottom row of three buttons: Quit / Backspace / Done. Pressing Down from the grid lands on that button row, Right moves along it, and Z on Done submits the current name.
- [FACT] After the name is submitted the main menu shows two items, Start Game and Settings. Arrow keys move the heart cursor, Z confirms.
- [FACT] The opening narration (black screen, white text) advances with Z.
Dialogue advances only by pressing confirm (Z or Enter); waiting forever does nothing.
Menus and choices are navigated with the arrow keys and confirmed with Z.
Movement on the map uses arrow keys only; W A S D do nothing.
Never press Esc in this game.
The title screen with UNDERTALE logo only responds to Z/Enter; walking does nothing there.
