# BetterAGI 使用手册

更新：2026-10-27

这套系统让大模型「玩」原神，并把整场过程录下来，后期用飞鱼音色配音、烧字幕
出成片。不直播、不推流。导演用 DeepSeek 官方平台（`deepseek-flash`，支持
图像输入），长期记忆用本地 OpenViking，语音用本地飞鱼 CosyVoice3。

## 0. 最短路径（环境已就绪时）

```bash

./.venv/Scripts/openviking-server.exe

# 2) AutoDL 控制台开机后，启动 Lumine（SSH 里）

# 3) 本机开 SSH 隧道（另开终端，输入 AutoDL 密码）

# 4) 打开原神和 BetterGI（管理员权限）

# 5) 录制 + 导演 + 操作桥（在 BetterGI/integrations/session 下）
cd /e/BetterAGI/BetterGI/integrations/session
/e/BetterAGI/Amaidesu/.venv/Scripts/python.exe run_episode.py \
    --token-file E:/BetterAGI/tools/bettergi_token.txt \
    --duration 1800 --capture window --window-title 原神 \
    --director-config ../lumine/director_config.json \
    --lumine-config ../lumine/bridge_config.json
```

运行前按第 4.2 节导出 DeepSeek/OpenViking 环境变量。录完后：

```bash

```


## 4. 一次性准备

### 4.1 BetterGI

1. 安装原神，确认窗口标题（默认 `原神`）。
2. 以管理员权限启动 BetterGI。
3. 设置 → 本机外部访问服务：打开 HTTP、WebSocket、MCP、智能体控制，端口
   `30648`。本机 `User/config.json` 已预置这些开关，令牌在
   `E:\BetterAGI\tools\bettergi_token.txt`，与设置页显示的令牌一致。
4. 游戏窗口保持前台；BetterGI 的模拟输入需要前台窗口。

### 4.2 DeepSeek

密钥已放在 `E:\BetterAGI\tools\deepseek_key.txt`。导演默认模型：

```text
LLM_PROVIDER=openai
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-flash
LLM_MAX_TOKENS=4096
OPENAI_REASONING_EFFORT=low
```

`deepseek-flash` 是当前官方支持图像输入的模型；`deepseek-v4-pro` 只支持文本。
DeepSeek 会先花几百 token 思考，`max_tokens` 必须给足，否则 `content` 为空。

导出环境（Git Bash）：

```bash
export LLM_PROVIDER=openai
export OPENAI_API_KEY="$(cat /e/BetterAGI/tools/deepseek_key.txt)"
export OPENAI_BASE_URL=https://api.deepseek.com/v1
export OPENAI_MODEL=deepseek-flash
export LLM_MAX_TOKENS=4096
export OPENAI_REASONING_EFFORT=low
export OPENVIKING_ENABLED=1
export OPENVIKING_URL=http://127.0.0.1:1933
```

也可以直接用 `integrations/lumine/run_director_deepseek.sh`，它自动读取密钥文件。

### 4.3 OpenViking（长期记忆）

独立环境，已安装 `openviking 0.5.2` 与本地嵌入 `bge-small-zh-v1.5-f16`。
配置文件：`C:\Users\Tsuba\.openviking\ov.conf`（VLM 指向 DeepSeek）。

```bash
cd /e/BetterAGI/openviking
./.venv/Scripts/openviking-server.exe doctor      # 可选，首次检查
./.venv/Scripts/openviking-server.exe             # 前台启动，保持终端
```

健康检查：`curl http://127.0.0.1:1933/health`，浏览器打开
`http://127.0.0.1:1933/` 可以看 OpenViking Studio。

导入设定资料：

```bash
/e/BetterAGI/openviking/.venv/Scripts/python.exe \
    /e/BetterAGI/BetterGI/integrations/lumine/memory_ingest.py \
    --path /e/BetterAGI/BetterGI/lore \
    --to "viking://~/resources/genshin"
```

首次导入会用 DeepSeek 生成摘要并建索引，可能需要几分钟。以后新增资料重复
执行即可，同路径会覆盖更新。

## 5. 录制一场

推荐顺序：

1. 开 OpenViking（终端 A）。
2. AutoDL 开机，启动 Lumine（SSH），本机建隧道（终端 B）。
3. 打开原神和 BetterGI（终端 C，管理员）。
4. 启动导演（终端 D）：

```bash
cd /e/BetterAGI/BetterGI/integrations/lumine
bash run_director_deepseek.sh --config director_config.json --interval 4
```

5. 启动操作桥（终端 E）：

```bash
/e/BetterAGI/Amaidesu/.venv/Scripts/python.exe \
    /e/BetterAGI/BetterGI/integrations/lumine/lumine_bridge.py \
    --config /e/BetterAGI/BetterGI/integrations/lumine/bridge_config.json
```

6. 启动录制（终端 F）：

```bash
cd /e/BetterAGI/BetterGI/integrations/session
/e/BetterAGI/Amaidesu/.venv/Scripts/python.exe record_session.py \
    --token-file E:/BetterAGI/tools/bettergi_token.txt \
    --start --stop-on-exit --duration 1800 \
    --capture window --window-title 原神 \
    --audio-device "立体声混音 (Realtek(R) Audio)" \
    --out sessions
```

`--start` 会启动 BetterGI 实时会话；`--stop-on-exit` 结束录制时停止它。
`--audio-device` 用 ffmpeg dshow 录游戏原音（设备名以本机为准，可省略）；
录到的文件是 `audio/game_audio.m4a`。
没有原神窗口时可用 `--capture frames`（WebSocket 帧合成），但窗口直录更流畅。

也可以由 `run_episode.py` 一次拉起导演与桥（第 0 节），它更适合无人值守。

## 6. 会话文件

```text
sessions/<会话id>/
    session.jsonl      # 唯一权威记录，逐行 JSON
    gameplay.mp4       # 整场画面
    subtitles.ass      # 后期生成
    final.mp4          # 后期成片
    render.json        # 配音对齐报告
    audio/             # TTS 产物
```

`session.jsonl` 的事件：`thought`、`speech`、`action`、`avatar`、`guidance`、
`note`、`video`、`audio`、`error`、`end`。所有时间用毫秒 `t`（相对录制起点）。
`audio` 事件记录游戏原音路径与设备；`speech` 还会带
`intensity/pace/volume/pause_before_ms/interruptible/thought_source`。

```bash
python show_session.py sessions/<会话id> --thoughts --actions
```

## 7. 后期成片

```bash
cd /e/BetterAGI/BetterGI/integrations/session

# 默认：飞鱼 cute（检测到环境时自动）
python render_session.py sessions/<会话id>

# 温柔声线
python render_session.py sessions/<会话id> --tts feiyu --feiyu-style gentle

# Windows 自带语音
python render_session.py sessions/<会话id> --tts sapi

# 只出字幕和画面
python render_session.py sessions/<会话id> --tts none
```

渲染器会把每条配音用 `atempo` 对齐到 `speech.dur`；句子太密时会自动顺延，
偏移写进 `render.json`。飞鱼失败可加 `--allow-tts-fallback` 回退 SAPI。

若会话里有 `audio/game_audio.m4a`，渲染会自动混入游戏原音，并在 AI 说话时
用 sidechain 压低原音；可用 `--game-audio 相对路径` 指定别的音轨，
或 `--no-game-audio` 关闭。语音的音量/停顿来自 `speech` 的 prosody 字段。

## 8. 记忆系统

### 短期

导演每轮让 DeepSeek 在 `memory_patch` 里维护：

- `scene`：当前地点/任务/威胁；
- `plot`：最近剧情进展；
- `objective`：当前目标。

加上最近 40 条事件（提示词取最近 8 条），就是短期剧情记忆。它们同时写入
BetterGI 会话记忆，进程重启后还能读回。

### 长期

- 设定/攻略：`viking://~/resources/genshin`，由 `lore/` 导入；
- 实况剧情：`viking://~/memories/genshin/live/<session_id>.md`，每 60 秒
  滚动写入，最多 60 行。

导演每轮用当前指导/场景检索两个子树，取最多 4 条注入提示词。OpenViking
没启动时自动降级，不影响录制。

查看/编辑：浏览器打开 `http://127.0.0.1:1933/`，在 Studio 的文件树里直接
看 Markdown。新增设定后重新执行 `memory_ingest.py`。

### 为什么不用 SuperMemory

官方自托管二进制不是开源引擎（只有 lite 许可），云端需要额外 API Key；
社区替代版是 Postgres+pgvector。当前优先自托管、可审计，所以选 OpenViking。
如果以后要云端同步，可在 `memory_bridge.py` 增加 SuperMemory 适配器，
`recall/remember_session` 接口不变。

更多设计见 `design/memory-system.md`。

## 9. VTuber 参数

`avatar` 事件保存 VTube Studio 参数：

- `pose`：每秒一次的头/身体角度、呼吸、眼球；
- `blink`：眨眼；
- `speech.avatar`：表情、嘴型、眉毛、50ms 口型包络。

离线成片目前只叠加静态头像（`--avatar-image`）；要真正渲染 Live2D，需要
另做 VTS 回放或浏览器 Live2D 渲染器。参数本身已完整保存在会话文件里。

## 11. 故障排查

| 现象 | 检查 |
|---|---|
| DeepSeek 返回空 content | `LLM_MAX_TOKENS=4096`；设 `OPENAI_REASONING_EFFORT=low`；确认模型是 `deepseek-flash` |
| DeepSeek 401/402 | 密钥/余额；`GET https://api.deepseek.com/models` |
| 导演连不上 BetterGI | BetterGI 是否管理员启动、智能体/HTTP/WS 是否打开、令牌是否匹配 |
| 录制没有画面 | 原神是否运行；窗口标题；`--capture window` 或 `frames`；实时会话是否启动 |
| 桥没有动作 | AutoDL 是否开机；`8010/health`；SSH 隧道；`LUMINE_SERVER_TOKEN` |
| AutoDL 动作很慢 | 约 0.4 秒/帧是当前上限；看 `vllm.log` 与 `/status` |
| OpenViking 检索为空 | 服务 `1933/health`；是否导入过 `lore/`；Studio 里是否有文件 |
| 飞鱼没声音 | 模型目录；`--allow-tts-fallback` 看错误；显存是否被其他程序占用 |
| 飞鱼报 `bad allocation` / speech_tokenizer 加载失败 | 本机内存/页面文件不足：关闭 OpenViking、GPT-SoVITS、浏览器等占内存程序后重试，或先用 `--tts sapi` |
| VTS 不响应 | 8001 端口；VTS 弹窗是否允许插件；`data/vts_token.txt` |
| 首次运行很慢 | 飞鱼首次加载约 14 秒；OpenViking 首次导入要建索引；Windows 杀毒软件可能拖慢 DLL 加载 |

## 12. 安全与许可

- BetterGI 只做图像识别与模拟输入，不读写游戏内存、不抓包、不注入。
- 令牌/密钥只在本地：`tools/*.txt`、`bridge_config.json`（已 gitignore）。
- OpenViking 只监听 127.0.0.1；不要暴露 8010/1933 到公网。
- OpenViking：AGPLv3；飞鱼/CosyVoice：上游 Apache-2.0，音色素材有作者授权
  范围；DeepSeek：按官方服务条款使用。
- 不要把 `.env`、密钥、录像中的个人信息提交到仓库。
