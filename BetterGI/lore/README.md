# 原神设定资料（长期记忆）

这个目录放「长期理解设定」用的资料。导演启动后通过 OpenViking 检索这里
的内容，作为提示词里的“长期记忆（设定/往事）”。

支持的格式：Markdown / 文本 / JSON。建议一个主题一个文件，文件名用英文或
拼音，正文用中文，每段控制在几百字，方便摘要与检索。

## 使用

```bash
# 把整个目录导入 OpenViking 的 genshin 资源树
E:\BetterAGI\openviking\.venv\Scripts\python.exe ^
    BetterGI/integrations/lumine/memory_ingest.py ^
    --path BetterGI/lore --to "viking://~/resources/genshin"
```

导入是增量的：同一路径重复导入会覆盖更新，不会重复堆叠。首次导入会用
DeepSeek 生成目录摘要并建立向量索引，几十秒到几分钟不等。

## 建议放什么

- 地区与城市：蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬……
- 角色：名字、所属、元素、性格、与旅行者的关系（避免剧透后期剧情）。
- 任务链：当前正在跑的任务目标、前置条件、已知情报。
- 世界观：元素反应、七神、深渊、愚人众等常见设定。
- 你希望主播“记得”的约定：称呼、口癖、观众梗、直播规则。

## 不要放什么

- 未授权的完整剧本文本、付费攻略原文；用你自己的话总结。
- 密钥、令牌、个人隐私。
- 会剧透尚未到达剧情的细节（除非你希望主播提前知道）。
